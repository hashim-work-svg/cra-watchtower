# Security Policy: CRA Vulnerability Watchtower

## Threat Model & Considerations

`cra-watchtower` processes external Software Bills of Materials (SBOMs), often generated by third-party build tools or suppliers.

| Risk Area | Mitigation Implemented | Residual Risk |
| :--- | :--- | :--- |
| **Malformed / Malicious SBOMs** | Strict JSON schema parsing with maximum read limits; rejection of unparseable inputs. | Deeply nested JSON structures causing memory spikes. |
| **PURL Injection / Spoofing** | Validation via official `packageurl-go` specification parser; canonicalization of schemes and types. | Novel, non-standard PURL custom qualifiers. |
| **Vulnerability Data Tampering** | Local caches verified with checksums; offline fixture fallback. | Stale local vulnerability data if sync is not scheduled. |
| **Premature / False Reporting** | Drafts are generated locally for human sign-off; zero automatic network transmissions to authorities. | Human operator filing inaccurate notifications without verification. |
